# ZERQON

Русскоязычный сайт технологической и инвестиционной группы. Новый графитовый интерфейс, Manrope с кириллицей, собственный геометрический Q, оригинальные предметные сцены и ровно шесть глав на главной. Данные пяти проектов, три официальных направления и 14 маршрутов сохранены.

## Работа с проектом

- `npm install`
- `npm run dev` — локальный просмотр.
- `npm run build` — TypeScript, Vite, SSR и пререндер всех страниц в `dist`.
- `npm run verify` — маршруты, ссылки, якоря, заголовки, статусы, метаданные и цветовые пары.
- `npm run preview` — просмотр готовой сборки.

## Архитектура

- `src/design.css` — единая актуальная система оформления и адаптивные композиции.
- `src/objects.css` — резервные кодовые предметные визуализации.
- `src/render.ts` — страницы, словесный знак и геометрическая эмблема.
- `src/content.ts` — реальные данные, статусы и названия направлений.
- `src/hero-geometry.ts` — общая геометрия нового пятикомпонентного Q.
- `src/scene.ts` — Three.js: освещение, ограниченная камера, разборка и лёгкая реакция на указатель.
- `src/scene-state.ts`, `src/motion.ts` — один источник целевого прогресса hero. Документ не закрепляется, текст не движется.
- `src/product-scene.ts` — ограниченные предметные последовательности Chainso и аппаратной концепции, повтор сборки.
- `src/header.ts` — навигация и нативный dialog с Escape и восстановлением фокуса.
- `src/interactions.ts` — валидация формы, доставка/сохранение и клавиатурные вкладки Labs.

Старые слои оформления отключены и сохранены в `review/rebirth/before/`. Они не участвуют в сборке. GSAP и Motion удалены из зависимостей; движение реализовано небольшими контроллерами для конкретных объектов.

## Доступность и движение

Текст и маршруты пререндерены. На мобильных, при Save-Data, reduced motion и `?motion=off` тяжёлые сцены не создаются. `?webgl=off` отдельно проверяет резервную графику. Сцены не перерисовываются постоянно после завершения движения, останавливаются вне видимости и при скрытой вкладке. Меню сохраняет геометрию страницы, использует нативное управление фокусом.

## Контент и форма

Chainso — активный проект. «Ресторанные технологии» — рабочее название инициативы в разработке; изображённое устройство является концептуальной визуализацией. Atlas, Nexus и Orbit — сохранённые исследовательские проекты/концепции. Биографии, портреты, достижения и контакты не выдумывались.

Без обработчика форма проверяет данные и сохраняет текстовый файл, явно сообщая, что отправки не было. Для существующего сервера задайте `VITE_CONTACT_ENDPOINT` до сборки. Отправляется JSON POST: `name`, `email`, `topic`, `message`, `consent`. При ошибке данные остаются в форме. Сервер отвечает за доставку, защиту от спама и валидацию; секреты не должны попадать в VITE-переменные.

Перед приёмом реальных обращений нужны утверждённые документы и реквизиты. `dist` — статический результат; для другого домена обновите базовый URL в `scripts/prerender.mjs`. Внешняя публикация в этом проходе не выполнялась.
