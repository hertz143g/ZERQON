# Доработка стабильности и читаемости

Удалены причины избыточного движения: GSAP/ScrollTrigger, закрепление первого экрана, привязанные к прокрутке разборки и повороты объектов, раскрывающиеся маски, поочерёдные вылеты строк меню, сдвиги документов при переходах, движение объектов/стрелок на hover. Удалены неиспользуемые cinematic.ts, hero-state.ts, product-state.ts. Сцены Three.js теперь неподвижны: draw вызывается по необходимости (размер/видимость), без непрерывного цикла и без обработчиков scroll/pointer. Загрузка предметных сцен откладывается в свободное время браузера.

Сохранены короткие изменения цвета кнопок и 120 ms появление меню. Устранён резкий переход CSS → WebGL: только короткое изменение прозрачности, без изменения размеров. На мобильных резервные объекты остаются видимыми, в том числе после перехода с большого экрана.

Минимальный размер информационных подписей — 14 px. Основной текст — 17–20 px. Увеличены навигация, статусы, подписи визуализаций, ссылки, примечания, подвал, вкладки и поля формы. Удалена лишняя подпись Q. Мобильные направления упрощены для читаемости; увеличен резерв места для описаний и метаданных.

## Проверка
- Сборка и npm run verify проходят.
- 70 сочетаний (14 страниц × 320/390/768/1440/2560): нет переполнения, ровно один h1, не выявлены видимые информационные тексты меньше 14 px и ошибки контраста. audit.json. Это DOM-проверка, не полная сертификация доступности.
- Дополнительно все 14 production-маршрутов проверены при 320 и 1440 px: production.json.
- Hero relative; высота sequence равна высоте hero. После прокрутки на 1832 px верх hero оказался на −1832 px, текст без transform. Закрепления и компенсирующего сдвига нет.
- Меню при 390 px: ширина шапки 347 px и left 14 px до/во время/после открытия. ScrollY остаётся 0, повторное открытие/закрытие работает, фокус возвращается на кнопку.
- Labs: при смене первой/последней вкладки высота описания осталась 110 px, начало следующего раздела — 1054.875 px. Home работает.
- Заключительная консоль без ошибок и предупреждений. Снимки в after/.

Основной JS ~36.7 KB / 11.52 KB gzip. Отдельный GSAP-бандл ~116 KB больше не загружается. Общий ленивый модуль Three.js остаётся ~517 KB / 130 KB gzip, Vite предупреждает о размере. Реальные fps, Lighthouse и реальные мобильные устройства не измерялись; без этих замеров не заявляется гарантия частоты кадров.
